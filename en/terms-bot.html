Users and server administrators expressly agree NOT to engage in, facilitate, or encourage any of the following conduct while using the Bot:

  2. Adversarial Prompt Injections (Jailbreaking): Deliberately crafting inputs intended to bypass AI safety filters (jailbreaks or adversarial prompt injections) to force generation of malicious, fraudulent, unlawful, or unethical content.
  3. Unlawful, Harmful, or Abusive Content: Using the Bot to generate, distribute, or facilitate hate speech, harassment, violent threats, extortion, child exploitation (CSAM), malware/spyware distribution, phishing, or third-party intellectual property infringement.
  4. Reverse Engineering & Credential Extraction: Decompiling, disassembling, reverse engineering, intercepting protected traffic, or attempting to extract Discord bot tokens, API keys, environment variables, or databases.
  5. NSFW Content Outside Designated Channels: Requesting or processing age-restricted (NSFW) content outside channels properly flagged as age-restricted in accordance with Discord guidelines and applicable law.

Zero-Tolerance Policy Against Abuse: Verified violations of any of the restrictions above will result in immediate permanent blacklisting of the User ID and/or Server ID from the Bot, as well as a formal report to Discord Trust & Safety.

07

Privacy & Basic Data Processing Overview

Data privacy and security are core pillars at RACM Artificial Intelligence & Data Science. Below is a transparent summary of the data processed by the Bot:

Data Collected / Processed Strict Technical Purpose Retention / Storage
Discord User ID (User Snowflake) Permission checks, rate-limit control, and routing replies back to the requesting user. Temporary in memory during session; persistent only for blacklists or saved preferences.
Server & Channel ID (Guild & Channel ID) Delivering responses to the originating channel and persisting server-specific settings. While the Bot remains installed on that server or until removal/purge request.
Command Inputs & Parameters Processing the prompt through the AI engine to generate the requested output. Ephemeral (volatile). Never used to train external public foundation models without consent.
Private Messages / Unrelated Channels The Bot DOES NOT read or store conversations outside explicit commands or mentions. Zero retention. Full compliance with Discord Message Content Intent rules.

No Data Sale: RACM does not sell, lease, trade, or share user or server data with advertisers, data brokers, or unrelated commercial third parties.

Right to Erasure (Right to be Forgotten): Server administrators and users may request complete deletion of any stored identifiers or settings at any time via the official channels in Section 12.
